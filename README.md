### ❤️ 1. CardioIQ — Cardiovascular Disease Prediction

**An explainable machine learning application developed as part of my MSc dissertation.**

Developed a machine learning pipeline using routinely collected health and lifestyle data to predict cardiovascular disease.

**Key Highlights**
- Compared Logistic Regression, Random Forest, and XGBoost models.
- Optimised XGBoost achieved **73.1% accuracy and 0.796 ROC-AUC** on the held-out test set.
- Used hyperparameter tuning and cross-validation to optimise model performance.
- Applied SHAP to explain feature importance and individual predictions.
- Developed a Streamlit application for interactive predictions and visualisations.

**Tech Stack:** Python · Pandas · Scikit-learn · XGBoost · SHAP · Streamlit
